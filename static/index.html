Lines are drawn straight between points; real routes differ. Lengths, capacities and positions are approximate.

Flows are calculated: field output and imports are routed to demand in each country's main cities and regions within pipeline capacities, cheapest routes first, with shortages shared out. LNG import terminals fill gaps only after reachable pipeline gas runs out, since LNG costs more. Fields can produce up to 10% extra and each region can cut up to 15% of demand, but only once cheaper options run out; LNG exports are served after domestic demand. Some pipelines and all national grids can run in reverse. Demand left after all that is the shortfall. Value = flow × ~10.55 TWh/bcm × gas price. Supply, demand and prices are assumptions set in gas_network.py. A node's value is the gas passing through it, so values overlap and shouldn't be added up.
